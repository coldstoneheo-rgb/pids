# 개인화된 투자 의사 결정 시스템 (PIDS)

**Personal Investment Decision System**

당신의 투자 철학을 시스템화하다.

## 소개

이 시스템은 일반적인 종목 추천 시스템이 아닌, **개인의 투자 성향과 전략에 맞춘 의사 결정 지원 시스템**입니다.

### 핵심 차별점

- **개인화**: 당신만의 투자 철학과 기준을 시스템에 반영
- **의사결정 중심**: 추천이 아닌, 체계적인 의사결정 프로세스 제공
- **투명성**: 모든 판단 근거를 명확히 제시
- **백테스팅**: 과거 데이터로 전략 검증 가능
- **학습과 개선**: 투자 기록을 통한 지속적 개선

## 주요 기능

### 1. 데이터 수집 및 분석
- 한국 주식 (KOSPI/KOSDAQ) 데이터 수집
- 미국 주식 (NYSE/NASDAQ) 데이터 수집
- 재무제표 및 기본적 분석
- 기술적 분석 (이동평균, RSI, MACD, 볼린저 밴드 등)

### 2. 종목 스크리닝
- 사용자 정의 기준에 따른 종목 필터링
- PBR, PER, 거래량, 시가총액 등 정량적 지표
- PBR 밴드 분석
- 유동성 체크

### 3. 의사결정 체크리스트
- 정량적 지표 평가
- 정성적 분석 (업종, 기업 경쟁력)
- 기술적 분석 (매수/매도 시점)
- 리스크 평가
- 종합 점수 및 최종 의사결정

### 4. 백테스팅
- 과거 데이터로 전략 검증
- 수익률, 샤프 비율, MDD 등 성과 지표
- 벤치마크 대비 성과 비교

### 5. 포트폴리오 관리
- 관심 종목 관리
- 포트폴리오 추적
- 리밸런싱 알림

## 설치 방법

### 1. 저장소 클론

```bash
git clone <repository_url>
cd math-learning-analyzer
```

### 2. 가상환경 생성 (권장)

```bash
python -m venv venv

# Windows
venv\Scripts\activate

# macOS/Linux
source venv/bin/activate
```

### 3. 패키지 설치

```bash
pip install -r requirements.txt
```

**중요**: `ta-lib` 설치는 시스템에 따라 추가 작업이 필요할 수 있습니다.

#### macOS:
```bash
brew install ta-lib
pip install ta-lib
```

#### Ubuntu/Debian:
```bash
sudo apt-get install libta-lib-dev
pip install ta-lib
```

#### Windows:
[TA-Lib 바이너리](https://www.lfd.uci.edu/~gohlke/pythonlibs/#ta-lib)를 다운로드하여 설치

## 사용 방법

### 1. 설정 파일 수정

투자 전략을 자신의 성향에 맞게 커스터마이즈하세요.

#### 투자 프로필 설정

```bash

```

- 위험 감수 성향
- 투자 기간
- 선호 투자 스타일
- 관심 섹터

#### 투자 전략 설정

```bash

```

- 스크리닝 기준 (PBR, PER, 거래량 등)
- 매수/매도 기준
- 포트폴리오 관리 규칙
- 리스크 관리 설정

### 2. 프로그램 실행

```bash

```

### 3. 메뉴 선택

```
1. 종목 분석 (단일 종목)
2. 종목 스크리닝 (조건 검색)
3. 관심 종목 관리
4. 포트폴리오 분석
5. 백테스팅
6. 설정 관리
0. 종료
```

## 투자 전략 예시 (기본 설정)

현재 시스템에 적용된 전략:

### 스크리닝 기준

1. **PBR**: 1.0 이하, PBR 밴드 하단 (하위 20%)
2. **PER**: 10~15배
3. **거래량**: 충분한 유동성 (일 거래대금 10억원 이상)
4. **시장**: 한국/미국 주식
5. **선호**: 기술주, 가치주, 업계 1등 기업

### 매수 전략

1. 가격 조정 완료 (고점 대비 10% 이상 조정)
2. 횡보 구간 (기간 조정)
3. 지지선 (전저점) 접근
4. RSI 과매도 구간 (< 40)
5. 이동평균선 지지
6. **분할 매수** (전저점 근처에서)

### 매도 전략

1. **목표 수익률**: 100~200%
2. **손절**: -20%
3. **분할 매도**:
   - 1차 익절: +50%
   - 2차 익절: +100%
   - 최종 청산: +200%

## 주의사항

### 면책 조항

이 시스템은 **교육 및 연구 목적**으로 제공됩니다.

- 시스템의 분석 결과는 참고용이며, 투자 권유가 아닙니다
- 모든 투자 결정과 그에 따른 손익은 투자자 본인의 책임입니다
- 과거 데이터 기반 백테스트 결과가 미래 수익을 보장하지 않습니다
- 시스템 사용 전 충분한 검증과 테스트를 권장합니다

### 데이터 제공자 정책

- **한국 주식**: pykrx, FinanceDataReader 사용
- **미국 주식**: yfinance 사용
- 각 데이터 제공자의 이용 약관을 준수해야 합니다
- API 호출 제한에 주의하세요

## FAQ

### Q: 이 시스템을 사용하면 수익이 보장되나요?

A: 아닙니다. 이 시스템은 의사결정 지원 도구일 뿐, 수익을 보장하지 않습니다. 투자는 본인의 판단과 책임 하에 이루어져야 합니다.

### Q: 실시간 데이터를 사용할 수 있나요?

A: 현재 버전은 지연 데이터를 사용합니다. 실시간 데이터는 유료 API가 필요하며, 추후 추가될 예정입니다.

### Q: 다른 투자 전략을 적용할 수 있나요?

A: 네! `config/strategy_config.yaml` 파일을 수정하여 자신만의 투자 전략을 적용할 수 있습니다. 이것이 이 시스템의 핵심입니다.

### Q: 암호화폐나 선물/옵션도 지원하나요?

A: 현재는 주식만 지원합니다. 향후 확장 가능합니다.

### Q: 자동 매매가 가능한가요?

A: 현재 버전은 의사결정 지원만 제공하며, 자동 매매 기능은 없습니다. 실제 거래는 증권사 앱을 통해 직접 수행해야 합니다.

### Q: Mac/Linux에서도 사용 가능한가요?

A: 네, Python이 실행되는 모든 플랫폼에서 사용 가능합니다.
